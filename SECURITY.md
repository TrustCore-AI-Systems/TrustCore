# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue, discussion or pull request.

Report security concerns privately to **[security@trustcore.fi](mailto:security@trustcore.fi)**.

A useful report includes:

- a concise description of the issue;
- the affected TrustCore-owned asset or URL;
- reproducible steps or a minimal proof of concept;
- the likely impact and any conditions required;
- relevant logs or screenshots with secrets and personal data removed;
- a safe way to contact you.

## Responsible testing

Please avoid actions that could expose other people's data, disrupt a service, destroy or alter data, degrade availability, or affect systems that TrustCore does not own. Do not move beyond the minimum verification needed to describe the issue. Wait for explicit written authorization before attempting broader access or any change to system state.

Third-party services and customer environments are outside scope unless TrustCore explicitly confirms otherwise in writing.

## Disclosure and rewards

Please allow time for assessment and coordinated remediation before public disclosure. We will agree any disclosure timing case by case.

This repository does not establish a bug-bounty program or promise a reward. Any reward or additional testing authorization must be agreed explicitly in writing.
