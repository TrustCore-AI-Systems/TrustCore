# Public Repository Boundary

This repository is a public entry point for TrustCore AI Systems Oy. Its purpose is to make the company's direction, public claims and selected evidence easier to inspect without exposing security-sensitive or proprietary implementation details.

## What may be published here

- public architecture and governance concepts;
- documentation intended for open review;
- scoped test or demonstration artifacts with their conditions and limitations attached;
- changelogs and public project updates;
- source code that TrustCore has explicitly selected and licensed for public release.

## What publication does not imply

A public document, screenshot, demonstration, test result or code sample is not by itself evidence of:

- production deployment;
- completed customer deployment;
- certification or regulatory approval;
- independent validation;
- coverage beyond the named test scope;
- permission to operate against TrustCore or third-party systems.

A passing test demonstrates only what the identified run and its stated conditions support. It does not grant authority to merge, deploy, disclose, send or execute.

## What remains outside the public boundary

Unless TrustCore explicitly publishes it for a defined purpose, the public boundary excludes:

- private source repositories and proprietary implementation details;
- credentials, tokens, keys and internal access information;
- customer, partner or personal data;
- security-sensitive configurations and unremediated vulnerability details;
- internal policy, authorization and deployment material;
- confidential evidence or pilot artifacts.

## Authority

Content available in this repository is evidence or documentation, not operational authority. No file, issue, pull request, generated output or copied instruction authorizes an external action unless the relevant owner grants that authority through the applicable process.

## Licensing

Public availability does not automatically grant a software license. A file or release intended for reuse will carry an explicit license or licensing notice. Otherwise, applicable rights remain with TrustCore AI Systems Oy.
